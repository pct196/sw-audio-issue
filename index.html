SDK loading...

The tone is handed to the SDK as inputAudioStream on a new leg. Nothing else on the page touches it after that, so anything that happens to it is the SDK's doing. Remove extra leg closes the most recent one through removeAdditionalDevice().

Closes the SDK's WebSocket from the client side so it reconnects while the call keeps running. Wait for signal-only reconnect in the log, then share the screen.

Reproduction 8. The first closes the socket as the next verto.ping arrives, so the SDK answers into a closing socket. The second closes it 300ms before the ping is due, so the server sends it into the gap. The third discards the SDK's verto.pong and leaves the socket alone. For the control, press Drop socket midway between pings. Then wait one interval: a hang-up shows as verto.bye.
